---

AquariumGPU is a browser-based 3D saltwater aquarium inspired by the classic SereneScreen Marine Aquarium screensaver.

For the best experience, use a recent version of Chrome or Edge on a computer with a dedicated GPU.

Features
* Real-time 3D rendering using WebGPU
* Animated tropical fish
* Procedurally generated reef environment
* Dynamic underwater lighting and water caustics
* Adaptive rendering quality for different GPUs
* Fullscreen viewing mode
* Lightweight, entirely client-side application

Technology
AquariumGPU uses JavaScript, WebGPU, and custom GPU shaders. Everything runs locally in your browser, without a backend server.

The project was developed with assistance from OpenAI Codex.

Origins and Acknowledgments
AquariumGPU is based on Abyssal Garden, created by Maksymilian Dendura.

The original project's WebGPU rendering architecture and procedural graphics techniques provided the foundation for AquariumGPU.
